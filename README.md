## English

This repository is currently inactive. Do not complete the practice workflow or submit anything during Week 1.

1. Open workflow.md and replace the username placeholder with your own GitHub
   username.
2. Commit and push that change to the default branch.
3. Create a branch named prep-01-practice.
4. Edit branch-practice.md on that branch and commit the change.
5. Open a pull request from prep-01-practice into the default branch.
6. Merge the pull request and paste its link into workflow.md.

Do not put your password, personal token, recovery codes, or two-factor
authentication codes in any file or message.
